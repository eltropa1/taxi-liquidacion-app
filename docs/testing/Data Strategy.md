# Data Strategy

## Propósito

Definir cómo se resetean y siembran los datos para ejecuciones E2E reproducibles.

## Alcance

Incluye reset lógico de base de datos, seed mínimo, aislamiento entre ejecuciones y control de estado para pruebas.

## Estructura prevista

- mecanismo de reset;
- mecanismo de seed;
- fixtures controladas;
- estado reproducible por ejecución.

## Estado actual

La estrategia está definida conceptualmente, pero todavía no existe implementación funcional.
