# Test IDs

## Propósito

Definir la convención oficial de selectores estables para la validación E2E.

## Alcance

Este documento será el contrato de selectores para pantallas, acciones, inputs, modales, listas, items y estados.

## Convención prevista

- `screen.*`
- `action.*`
- `input.*`
- `modal.*`
- `list.*`
- `item.*`
- `status.*`

## Estado actual

La convención está aprobada como contrato, pero todavía no se ha aplicado a la UI.
