# Research

## Objetivo

Esta carpeta contiene las investigaciones que sirven como base para construir el sistema de diseño de GeoTaxi.

Las investigaciones no contienen reglas oficiales.

Su misión es recopilar evidencia, estudiar el estado del arte y extraer conclusiones.

Las reglas oficiales vivirán posteriormente en `GeoTaxi UI Guidelines`.

---

## Flujo oficial de trabajo

Toda regla de UX, UI o diseño visual debe pasar por este flujo:

Investigación

↓

Documento de investigación

↓

Extracción de reglas

↓

GeoTaxi UI Guidelines

↓

Wireframes

↓

Mockups

↓

Implementación

Ninguna regla de UX o UI debe incorporarse directamente al proyecto sin haber pasado previamente por este flujo.

---

## Estructura de una investigación

Todas las investigaciones deberán seguir exactamente esta estructura:

1. Objetivo
2. Estado del arte
3. Consenso encontrado
4. Adaptación a GeoTaxi
5. Reglas candidatas
6. Impacto en GeoTaxi
7. Próximos pasos

---

## Entregables obligatorios

Toda investigación deberá finalizar con una tabla como la siguiente:

| Hallazgo | Regla candidata GeoTaxi | Pantallas afectadas |
|---|---|---|

Esta tabla permitirá transformar posteriormente las investigaciones en `GeoTaxi UI Guidelines`.

## Estados de una investigación

Las investigaciones oficiales de GeoTaxi deberán indicar claramente su estado actual.

### 🟡 En investigación

La investigación está en desarrollo.

### 🟠 Pendiente de validación

La investigación está terminada pero todavía no se han aprobado sus conclusiones.

### 🟢 Aprobada

Las decisiones finales han sido aprobadas y pueden incorporarse al sistema de diseño.

### 🔵 Incorporada a GeoTaxi UI Guidelines

Las decisiones ya forman parte oficialmente del sistema de diseño de GeoTaxi.
